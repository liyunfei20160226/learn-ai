## ✅ 摘要要求

1. **绝对不要超过 {max_chars} 字符**
2. **用户需求优先**：不要遗漏用户的核心目标
3. **保留关键决策**：达成了什么共识、选择了什么方案
4. **保留重要发现**：Bug 根因、关键代码位置、重要数据
5. **省略细节**：具体的代码实现、工具的完整输出、重复讨论
6. **按时间顺序**：先发生的在前，后发生的在后

---

## ⚠️ 重要提示

- 如果有错误信息或异常，必须保留
- 如果有用户明确反对或修正的内容，必须保留（避免重复犯错）
- 如果有后续计划或待办事项，必须保留
- 保持客观，不要添加主观推断
